# NEUROVA — AI Workspace

Готовый стартовый проект премиальной тёмной AI-платформы.

## Что внутри
- Адаптивный лендинг и рабочая панель инструментов.
- Четыре режима: копирайтер, генератор идей, посты для соцсетей, планировщик.
- Копирование результата.
- Серверный endpoint `/api/generate`.
- Демо-режим без API-ключа.
- Подключение OpenAI Responses API через сервер (ключ не попадает в браузер).

## Запуск локально
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000

Без ключа сервер отвечает демо-текстом — интерфейс и маршруты можно проверить.

## Включить настоящую AI-генерацию
1. Создайте API key в кабинете OpenAI.
2. Установите переменную окружения `OPENAI_API_KEY`.
3. При необходимости задайте `OPENAI_MODEL` (по умолчанию `gpt-5-mini`).
4. Перезапустите сервер.

Пример для macOS/Linux:
```bash
OPENAI_API_KEY="ваш_ключ" npm start
```

Пример для PowerShell:
```powershell
$env:OPENAI_API_KEY="ваш_ключ"
npm start
```

Никогда не вставляйте API-ключ в `public/index.html`, не публикуйте его в GitHub и не отправляйте клиентскому JavaScript.

## Что требуется перед коммерческим запуском
Это MVP, а не готовый коммерческий SaaS. Перед приёмом денег добавьте:
- регистрацию, вход и восстановление пароля;
- базу данных пользователей, истории и лимитов;
- серверную проверку тарифов и квот;
- реальную оплату через платёжного провайдера, доступного в вашей стране;
- политику конфиденциальности, пользовательское соглашение и контакты;
- rate limiting, защиту от злоупотреблений, логи и мониторинг;
- резервный бюджет на AI API и тестирование спроса.

Кнопка тарифа PRO сейчас демонстрационная и не принимает оплату. Не рекламируйте подписку как активную, пока платёжный процесс и учёт доступа не реализованы.
